# ft_package

A simple Python package created for the Python for Data Science training project.

## Description

`ft_package` provides a simple function called `count_in_list`.

It returns the number of occurrences of a given value inside a list.

## Installation

After building the package, it can be installed with:

```bash
pip install ./dist/ft_package-0.0.1.tar.gz
pip install ./dist/ft_package-0.0.1-py3-none-any.whl
